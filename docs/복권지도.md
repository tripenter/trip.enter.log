# 시·군·구 지도 모듈 사용 매뉴얼 (에이전트용)

대한민국 시·군·구 경계를 표시하고, 지역별 데이터(메뉴·텍스트·사진 등)를 연결하는 프론트엔드 모듈이다.  
배율 고정, 확대/축소·드래그 없음, 호버/클릭 팝업을 공통으로 제공한다.

에이전트가 새 페이지에 지도를 넣을 때 **이 문서를 먼저 읽고** `TripEnterSigMap` 코어를 재사용할 것. 지도 로직을 페이지에 복붙하지 말 것.

---

## 1. 파일 구성

| 경로 | 역할 |
| --- | --- |
| `web/js/korea-sig-map.js` | **코어 모듈** (`window.TripEnterSigMap`) — 지도·지역·하이라이트·팝업 타이밍 |
| `web/js/korea-map.js` | 인트로(`index.html`)용 **WebMenu 어댑터** 예시 |
| `web/css/korea-map.css` | 지도/팝업/지역명 툴팁 스타일 |
| `web/data/korea-sig.geojson` | 시·군·구 GeoJSON (`name`, `code`) |
| `web/index.html` | Leaflet + 코어 + 메뉴 어댑터 연결 예시 |

의존성: **Leaflet 1.9.x** (`window.L`)가 먼저 로드되어야 한다.

## 2. HTML에 넣는 최소 구성

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.css" />
<link rel="stylesheet" href="/css/korea-map.css" />

<div class="korea-map-frame">
  <div id="korea-map" class="korea-map" role="application" aria-label="대한민국 시·군·구 지도"></div>
  <p class="korea-map-status font-mono" data-korea-status></p>
</div>

<script src="https://cdn.jsdelivr.net/npm/leaflet@1.9.4/dist/leaflet.js" defer></script>
<script src="/js/korea-sig-map.js" defer></script>
<script src="/js/your-page-map.js" defer></script>
```

- `#korea-map` (또는 `el`로 지정한 요소) 필수
- `data-korea-status`는 선택 (상태 문구용)
- GeoJSON 기본 경로: `/data/korea-sig.geojson`  
  하위 폴더 페이지면 `geoUrl`을 상대/절대 경로로 넘길 것

## 3. 코어 API: `TripEnterSigMap.create(options)`

```js
const instance = TripEnterSigMap.create({
  el: "#korea-map",
  statusEl: "[data-korea-status]",
  geoUrl: "/data/korea-sig.geojson",
  loadItems: async ({ districts, map, collection }) => {
    // 반드시 각 item에 codes: string[] 포함
    return [
      {
        codes: ["36010"], // 목포시 등 시군구 코드
        title: "예시",
        // 페이지가 필요한 필드 자유 추가 (href, image, text, ...)
      },
    ];
  },
  renderHoverPopup: (items, ctx) => {
    // ctx: { code, name, latlng, district }
    return `<div>...</div>`;
  },
  renderEmptyClick: (ctx) => `<p class="korea-soon-text">연결된 항목이 없습니다</p>`,
  onPopupReady: (root, items, ctx) => { /* 이미지 fallback 등 */ },
  onRegionEnter: ({ code, name, items, latlng }) => {},
  onRegionLeave: ({ code, name, items }) => {},
  onRegionClick: ({ code, name, items, latlng }) => {},
});

instance.ready.then(({ map, districts, setItems, destroy }) => {
  // 준비 완료
});
```

### 3.1 options

| 옵션 | 필수 | 기본 | 설명 |
| --- | --- | --- | --- |
| `el` | ✅ | — | 지도 마운트 요소 또는 셀렉터 |
| `statusEl` | | — | 하단 상태 문구 요소 |
| `geoUrl` | | `/data/korea-sig.geojson` | GeoJSON URL |
| `zoomOffset` | | `1` | fitBounds 후 추가 확대 단계 |
| `popupHideDelay` | | `500` | 다른 지역으로 처음 나간 뒤 팝업 닫힘(ms). **타이머는 리셋되지 않음** |
| `emptyClickDuration` | | `3000` | 빈 지역 클릭 안내 팝업 표시 시간(ms) |
| `items` | | — | 정적 아이템 배열 (`loadItems` 대신) |
| `loadItems` | | — | `async ({ districts, map, collection }) => items[]` |
| `renderHoverPopup` | | 간단 텍스트 | `(items, ctx) => HTMLString` |
| `renderEmptyClick` | | 기본 문구 | `(ctx) => HTMLString \| null` (`null`이면 표시 안 함) |
| `onPopupReady` | | — | 팝업 DOM 준비 후 `(root, items, ctx) => void` |
| `onRegionEnter` / `Leave` / `Click` | | — | 지역 이벤트 훅 |
| `messages.idle` | | 기본 문구 | 데이터 없을 때 상태 |
| `messages.withItems` | | 기본 문구 | 데이터 있을 때 상태 |
| `messages.emptyClick` | | `""` | 빈 클릭 시 상태 문구 |
| `popupClassName` | | `korea-choice-popup` | 호버 팝업 CSS 클래스 |
| `popupOffset` | | `[0, -11]` | Leaflet popup offset |
| `popupMaxWidth` | | `280` | 팝업 최대 너비 |
| `popupCloseButton` | | `true` | 닫기 버튼 |

### 3.2 create() 반환값

| 멤버 | 설명 |
| --- | --- |
| `ready` | Promise → `{ map, districts, getItemsByCode, setItems, destroy }` |
| `map` | Leaflet map (ready 전에도 생성됨) |
| `setItems(items)` | 아이템 다시 넣어 하이라이트/팝업 데이터 갱신 |
| `setStatus(text)` | 상태 문구 갱신 |
| `displayDistrictName` / `escapeHtml` | 유틸 바로 사용 |

### 3.3 아이템 스키마 (최소)

```ts
type SigMapItem = {
  codes: string[]; // 필수. GeoJSON properties.code (예: "36010")
  // 아래는 페이지 자유 필드
  title?: string;
  href?: string;
  covers?: string[];
  text?: string;
  image?: string;
  [key: string]: unknown;
};
```

`codes`에 포함된 시·군·구만 주황 하이라이트 + 호버 목록 대상이 된다.

## 4. 동작 규칙 (코어 고정 동작)

에이전트가 바꾸지 말고 그대로 전제할 것.

1. **고정 뷰**: dragging / scrollWheelZoom / doubleClickZoom / touchZoom / boxZoom / keyboard / zoomControl 모두 off. minZoom === maxZoom (시작 배율 고정).
2. **빈 지역 호버**: 지역명 툴팁 (`korea-name-label`, 커서 아래 둥근 박스). 예: `대전 유성구`, `강원도 영월군`.
3. **데이터 있는 지역 호버**: `renderHoverPopup` HTML 팝업. 지역 중심 근처 고정(마우스 추적 안 함).
4. **다른 지역으로 이동**: 팝업 닫힘 타이머는 **최초 1회만** 시작 (`popupHideDelay`). 연속으로 다른 지역을 스쳐도 리셋하지 않음. 원래 데이터 지역/팝업으로 돌아오면 타이머 취소.
5. **빈 지역 클릭**: `renderEmptyClick` 표시 후 `emptyClickDuration` 뒤 자동 닫힘.
6. **데이터 지역 테두리**: 상위 pane에서만 그려 인접 채우기에 가리지 않음.

## 5. 유틸 (제목 → 시군구 매칭)

메뉴/콘텐츠 제목으로 지역을 찾을 때:

```js
const { matchDistrictByTitle, prefixesFromContext, displayDistrictName } = TripEnterSigMap;

const hit = matchDistrictByTitle(
  "목포 갓바위",
  districts,
  prefixesFromContext([{ title: "광주/전라", folder: "jeolla" }]) // 선택적 스코프
);

// hit = { codes, label, lat, lng, anchorKey, districts } | null
```

| 유틸 | 용도 |
| --- | --- |
| `buildDistricts(geojson)` | feature → district 목록 |
| `displayDistrictName(name, code)` | `유성구` → `대전 유성구` |
| `matchDistrictByRegion(region, districts, scope?)` | `WM_Region` ↔ GeoJSON `name` 정확 매칭 |
| `matchDistrictByTitle(title, districts, scope?)` | 제목 문자열 안 지명 매칭 |
| `prefixesFromContext(nodes)` | `{ title, folder }[]`에서 광역 스코프 Set |
| `indexItemsByCode(items)` | code → items[] Map |
| `FOLDER_REGIONS` | 폴더명 → 코드 prefix (예: `jeolla` → `35`,`36`) |
| `REGION_BY_PREFIX` | prefix → 서울/경기도 등 라벨 |
| `escapeHtml` / `formatName` | 출력 헬퍼 |

중복 지명(중구, 고성군 등)은 `prefixesFromContext`로 광역을 좁히는 것이 안전하다.

## 6. 페이지별 연동 패턴

### 6.1 WebMenu (현재 index)

참고 구현: `web/js/korea-map.js`

1. `POST /rest/get/menu`로 메뉴 트리 로드  
2. 하위 메뉴는 `region`(`WM_Region`)이 GeoJSON `name`과 **동일**할 때만 `matchDistrictByRegion`으로 지도에 올린다 (`title` 폴백 없음)  
3. item에 `codes`, `href`, `covers`, `title`, `region` 넣기  
4. `renderHoverPopup`에서 썸네일+링크 목록 HTML  
5. 메뉴 등록 시 `webmenu-add` 스킬에서 `WM_Region`을 입력·정규화한다 (예: `영월군`)

### 6.2 텍스트/사진 등 임의 데이터

```js
TripEnterSigMap.create({
  el: "#korea-map",
  loadItems: async () => {
    const rows = await fetch("/rest/...").then((r) => r.json());
    return rows.map((row) => ({
      codes: [row.sigunguCode], // 또는 matchDistrictByTitle로 산출
      title: row.title,
      text: row.body,
      image: row.imageUrl,
    }));
  },
  renderHoverPopup: (items, ctx) => `
    <div class="korea-choice">
      <p class="korea-choice-heading">${TripEnterSigMap.escapeHtml(ctx.name)}</p>
      ${items
        .map(
          (it) => `
        <div class="korea-choice-item">
          ${it.image ? `<img src="${TripEnterSigMap.escapeHtml(it.image)}" alt="" />` : ""}
          <strong>${TripEnterSigMap.escapeHtml(it.title || "")}</strong>
          <p>${TripEnterSigMap.escapeHtml(it.text || "")}</p>
        </div>`
        )
        .join("")}
    </div>
  `,
  renderEmptyClick: () => `<p class="korea-soon-text">아직 기록이 없어요</p>`,
});
```

런타임에 데이터가 바뀌면:

```js
const { setItems } = await instance.ready;
setItems(nextItems);
```

## 7. 에이전트 체크리스트

새 페이지에 지도 추가 시:

1. [ ] Leaflet CSS/JS + `korea-map.css` + `korea-sig-map.js` 로드
2. [ ] `#korea-map` (높이 있는 `.korea-map`) 마크업
3. [ ] 페이지 전용 스크립트에서 `TripEnterSigMap.create` 호출
4. [ ] `loadItems`/`items`의 모든 항목에 `codes[]` 설정
5. [ ] `renderHoverPopup`으로 해당 페이지 UI(메뉴/텍스트/사진) 렌더
6. [ ] 지도 엔진 로직을 `korea-sig-map.js` 밖으로 복사하지 않음
7. [ ] 하위 경로면 `geoUrl`이 실제로 GeoJSON을 가리키는지 확인
