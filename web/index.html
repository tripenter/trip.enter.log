// brand.meaning

          
하나의 이름, 두 개의 길

          

            트립엔터는 여행과 입력을 한곳에 겹쳐 둔 이름입니다. 길을 떠나며 만난 장소를,
            엔터를 치듯 기록 속에 남깁니다.
          


          

            

              README.md
              type Brand
            

            

              

                
export type TripEnter =

                
trip + Enter

                

                  여행(trip)과 엔터키(Enter).
                  새로운 장소에 발을 들이고, 그 순간의 감각을 코드처럼 확정합니다.
                

              

              

                
| TripAndPlace

                
trip and place(터)

                

                  여행(trip) 엔(and) 터(place).
                  길 위의 나와, 그곳이 품은 터를 함께 이야기합니다.
                

              

            

          

        

      


      

        

          
// src/modules

          
캠핑 · 여행 · 코딩

          

            장소를 찾고, 코드로 담고, 엔터로 남깁니다.
            반응형 감성 미디어 아트로, 여행지에서 있었던 일과 감동을 코드로 기록하고,

            프로그램·게임 같은 웹 경험을 만듭니다.

          


          

            

              
modules/camp.ts

              
              camp.stealth = 0.8
              
탐색

              

                카메라를 들고 세상의 숨겨진 장소를 찾아 떠납니다.

                여행의 시작, 이른 공기, 이슬 맺힌 풀, 고요한 아침.

                길 위의 쉼을 화면 위에 펼칩니다.
              

            

            

              
modules/travel.ts

              
              travel.hotel = 0.2
              
여행

              

                여행에서 느낀 감동과 정보를 코드에 담아냅니다.

                호텔에 머무는 여정도, 길 위의 우연도.

                장소의 표정을 짧게, 또렷하게 담습니다.
              

            

            

              
modules/code.ts

              
              write.place()
              
코딩

              

                키보드의 엔터키를 누르는 순간,

                그곳은 단순한 공간에서 영원한 디지털 자산이 됩니다.

                HTML과 인터랙션으로 장소를 기록합니다.

                코드는 지도가 되고, 페이지는 여행 일지가 됩니다.
